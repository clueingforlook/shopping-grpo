# WLX Eval v2：典型轨迹

以下案例均来自 Eval v2 的正式结果。五项分数顺序为：搜索策略、候选利用、证据核验、购买决策、终止效率。

| 类型 | 模型 | task_id | 五项分数 | 结果 |
|---|---|---:|---|---|
| 完整成功 | SFT | 17354 | 2 / 2 / 2 / 2 / 2 | 目标商品成功 |
| 同任务由循环变成功 | Base → SFT | 7670 | 1/1/0/0/0 → 2/2/2/2/2 | 未购买 → 成功 |
| 商品正确但尺码错误 | SFT | 20117 | 2 / 2 / 1 / 0 / 0 | 部分符合 |
| 多个约束同时违反 | SFT | 9610 | 1 / 0 / 0 / 0 / 0 | 错误购买、需复核 |
| 已找到商品却没有结束 | Base | 20133 | 2 / 2 / 2 / 1 / 0 | 未购买 |
| 环境与 Judge 冲突 | SFT | 3025 | 2 / 2 / 2 / 2 / 2 | 环境判部分符合 |

完整消息和页面 Observation 保存在 Base/SFT 的 `wlx-trajectories.jsonl`，可按 `task_id` 查询。

## 1. 完整成功：SFT，task_id=17354

用户需要适合秋冬混干皮、保湿水润、含酵母精华、自然肤色的粉底液。SFT 搜索“保湿粉底液 酵母精华”，打开第一条强候选，选择“W02 适合黄皮自然肤色”并购买。

最终商品的标题、属性和选项覆盖全部需求，五项过程能力均为 2。这个案例体现了理想路径：简洁搜索、直接利用强候选、选择正确规格、及时购买。

同一任务的 Base 也打开了同一商品，但随后调用当前页面不可用的动作，最终未购买。这说明两者的差距主要发生在搜索之后。

## 2. 同一任务由循环变成功：task_id=7670

用户需要从电磁灶拆下的二手功率管、混装、20 只以上，预算约 30 元。

Base 多次搜索“功率管 20只装”，不断打开不同商品，却没有围绕已经出现的拆机候选核对规格，最终耗尽预算。SFT 则搜索“功率管 20只 拆机”，打开匹配商品，选择“一包30只”，以 32 元购买成功。

这条成对轨迹清楚展示了 SFT 学到的内容：不仅会搜索，还能利用候选、选择数量并结束任务。

## 3. 商品方向正确，但尺码错误：SFT，task_id=20117

用户要求黑色复古低帮 AJ1，尺码必须为 42.5，预算约 760 元。SFT 找到正确款式和颜色，却选择了 42 码并购买。

环境结果为部分符合，Rubric 明确把“42.5 码”判为违反，首要失败是规格/选项错误。搜索和候选利用均为 2，但购买决策与终止效率为 0，说明“找到对的商品”不能替代最终规格验证。

## 4. 多个约束同时违反：SFT，task_id=9610

用户要求橘色、约 1.5×2.5 米、打孔安装、强遮光隔热且不超过 100 元的窗帘。SFT 选择了蓝咖色、1.5×2.7 米、166 元的商品并购买。

颜色、高度和预算都有明确反证，最终为错误购买，五项过程分接近最低。同时，终局审计中的 `instruction_text` 与当前任务不一致，因此该轨迹进入复核队列：这里既有模型选择错误，也存在环境数据异常，不能只归咎于一方。

## 5. 已经找到商品，却没有结束：Base，task_id=20133

用户需要夏季女孩西装连衣裙，轻薄、韩系、粉红色、适合约 130 cm 身高，预算约 60 元。

Base 找到并多次打开同一个高度匹配候选，页面已经提供充分证据，但它持续重复搜索和打开，最终没有购买。因此搜索、候选利用和证据核验较好，终止效率为 0。

SFT 在同一任务中选择 130 cm 和粉红色，以 60 元购买成功。这个案例说明终止能力是独立于搜索与核验的关键能力。

## 6. 环境结果与 Judge 冲突：SFT，task_id=3025

用户要白色玻璃纤维空心管，约外径 1 厘米多、内径 1 厘米、长 1 米且不超过 15 元。SFT 选择“外10×内6.1mm白色1米”，价格 9 元。

环境验证器因内径不符合而判为部分购买，首要失败为规格错误；但 V4 Pro 把全部 Rubric 和五项过程都判为满足。这里 Judge 明显漏掉了“内径约 1 厘米”和“6.1mm”的差异。

该案例说明为什么环境结果、Rubric Judge 和复核队列必须分开保留，也说明证据核验分不能直接作为未经审计的 Reward。

## 对后续 RL 的启发

优先考虑稳定、可验证的信号：最终是否购买、价格是否违反明确预算、最终选择的规格是否满足硬要求、是否出现非法动作或循环。LLM 过程分更适合诊断和抽样，不宜直接整体转换成训练奖励。
